# 카드 거래 이상 탐지: 규칙 설계와 평가

카드 거래 55만 건을 SQL과 Python으로 분석해 이상 거래 탐지 규칙을 설계하고,
정밀도·재현율 기반으로 평가하며 실패 케이스의 원인을 분석한 프로젝트입니다.

- 데이터: Kaggle "Credit Card Transactions Fraud Detection Dataset"의 fraudTest.csv
  (Sparkov로 생성한 시뮬레이션 데이터, 2020-06-21 ~ 2020-12-31)
- 규모: 거래 555,719건, 카드 924장, 사기 2,145건(0.39%)
- 사용 기술: Python(pandas, matplotlib), SQLite(GROUP BY, CASE WHEN, 윈도우 함수, CTE)

## 핵심 결과

| 지표 | 결과 |
|---|---|
| 경보 기준 | 규칙 4개 중 3개 이상 위반 (하루 약 15건) |
| 정밀도 | 47.1% (무작위 선택 시 0.39%) |
| 재현율 | 62.0% |
| 도용 카드 탐지 | 218장 중 183장 (84%) |
| 피해 방어 가능 금액 | 전체 사기 금액의 72.1% (첫 경보 시 카드 정지 가정) |

## 분석 과정

### 1. 탐색: 사기 거래는 무엇이 다른가
- 심야(22~03시) 사기 비율 1.39%로 주간(0.08%)의 약 17배, 사기의 84%가 심야에 발생
- 300달러 이상 결제의 사기 비율 11.52%
- 20달러 미만 소액의 사기 비율(0.19%)이 중간 금액(0.11%)보다 높음: 고액 결제 전 카드 유효성을 확인하는 '카드 테스팅' 패턴으로 추정

### 2. 피처 설계: 고객별 '평소'와 비교
같은 300달러라도 고객마다 의미가 다르므로, SQL 윈도우 함수로 고객별 과거 이력을 계산했습니다.
이번 거래 이전 기록만 사용(`ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING`)해
미래 정보가 섞이는 데이터 누수를 막았습니다.

### 3. 탐지 규칙
| 규칙 | 조건 |
|---|---|
| R1 고액 결제 | 평소 평균 금액의 3배 이상 |
| R2 지출 급증 | 최근 24시간 지출이 평소 하루 지출의 4배 이상 |
| R3 심야 반복 | 최근 24시간 내 심야 결제 3건 이상 |
| R4 고액 반복 | 최근 24시간 내 평소 3배 이상 결제 3건 이상 |

개별 규칙은 약했지만(R3는 8.5만 건에 발동), 동시에 위반한 규칙 수가 많을수록
사기 비율이 급상승했습니다(3개 25.6%, 4개 87.7%).

### 4. 평가
- **정확도를 쓰지 않은 이유**: 모든 거래를 '정상'으로 판정해도 정확도가 99.61%입니다.
  실제로 사기를 62% 잡는 이 탐지기의 정확도(99.58%)가 오히려 더 낮게 나왔습니다.
- **경보 기준 선택**: 1~4점 기준을 비교해, 심사 인력이 감당할 수 있는 하루 경보 수 안에서
  가장 많이 잡는 3점 이상을 선택했습니다.

| 기준 | 하루 경보 | 정밀도 | 재현율 |
|---|---|---|---|
| 1점 이상 | 604.6건 | 1.7% | 92.2% |
| 2점 이상 | 78.1건 | 10.7% | 75.5% |
| **3점 이상** | **14.6건** | **47.1%** | **62.0%** |
| 4점 이상 | 5.0건 | 87.7% | 40.0% |

### 5. 실패 케이스 분석: 12월 오탐 급증
월별 정밀도가 50~74%로 유지되다 12월에 16.8%로 급락했습니다.
12월 지출이 전월 대비 약 2배로 늘면서, 정상 고객의 연말 소비를 '평소보다 많이 쓰는'
이상 행동으로 오인한 것이 원인입니다.

**개선 방향**: 평소 기준을 최근 30일로 갱신하거나, 같은 날 전체 고객의 소비 증가율을 함께 반영
